# `@getops/web`

React and TypeScript client for the getOPS training workspace.

```bash
npm run dev --workspace @getops/web
npm run typecheck --workspace @getops/web
npm run build --workspace @getops/web
```

The Vite development server proxies `/api` to the C++ API on
`http://127.0.0.1:8780`. New UI work belongs in a feature folder under `src`.
